# Client's Business Website

Complete single-page application developed for a client's business. The existing design was refined to present their services professionally, with a strong focus on clarity and simplicity in UI and UX.

## 🛠 Tech Stack
Design: Figma - designed to adapt to the already existing brand
Frontend: React, TypeScript, TailwindCSS, Keen Slider, Web3Forms
CI/CD: GitHub Actions + GitHub Pages with custom domain

## ✨ Features

### Custom Design
- Tailored aesthetic to match client's brand identity
- Responsive layout across all device sizes - Mobile first
- Thoughtful typography and visual hierarchy

### Performance & SEO
- Optimized load times and Core Web Vitals
- Semantic HTML structure for search engines
- Meta tags and Open Graph optimization
- Efficient asset loading and compression

### Accessibility & UX
- WCAG-compliant implementation
- Keyboard navigation support
- Screen reader compatibility
- Cross-browser testing and optimization

### Development
- TypeScript for enhanced maintainability
- Component-based architecture with TailwindCSS
- Clean, scalable codebase structure

## ⚙️ Development

```bash
npm run dev       # Start development server
npm run build     # Create production build
npx serve dist    # Preview production build
```

## 🚀 Deployment

Automated CI/CD pipeline using GitHub Actions:
- Automated builds on code changes (pushes to main)
- Custom domain configuration
